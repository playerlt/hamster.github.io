Claude Code 迁移到 EC2：从合盖即断到 7×24 运行

发表于 2026-03-13

把 Claude Code 从本地 Mac 迁移到 EC2，核心动机很简单：本地跑 Agent 合盖就断，定时任务不可靠。迁移后变成 7×24 不间断运行。

当前 .openclaw 目录结构

迁移步骤

1. 本地打包

2. 传到 EC2

3. 云端解压

4. 启动 Claude Code

四个关键坑

坑 1 - 认证方式：本地用 API Key（存在 credentials/ 下），云端推荐改用 IAM 角色 + Amazon Bedrock，openclaw.json 中 provider 从 anthropic 改为 amazon-bedrock，删掉 apiKey 字段。不想折腾 IAM 的话直接保留 API Key 也能跑。

坑 2 - 路径硬编码：部分配置文件里可能有 /Users/yourname/.openclaw 的绝对路径，需批量替换为 /home/ubuntu/.openclaw：

坑 3 - 时区：cron/ 下的定时任务如果按北京时间写的，云端 UTC 需减 8 小时。

坑 4 - 外部渠道：飞书（feishu/）、Telegram 等 webhook 地址需更新为新 EC2 的 IP 或域名。

让 Claude Code 后台常驻

或者写成 systemd service 开机自启。

迁移整体不复杂，主要时间花在处理路径和认证上，大概 30-40 分钟搞定。
